# Slot Machine

## Descripción

Este proyecto implementa un simulador de una máquina tragamonedas.
La máquina está formada por ruedas y símbolos de diferentes colores.

## Funcionalidades

- Crear una máquina tragamonedas.
- Adicionar ruedas.
- Eliminar ruedas.
- Adicionar símbolos.
- Eliminar símbolos.
- Girar ruedas.
- Consultar símbolos.
- Verificar la configuración ganadora.
- Mostrar u ocultar el simulador.

## Clases

### SlotMachine
Representa la máquina tragamonedas y controla sus operaciones.

### Wheel
Representa una rueda de la máquina y controla su posición.

### Symbol
Representa un símbolo de color.
